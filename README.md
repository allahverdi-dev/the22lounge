# The 22

Premium responsive lounge & dining concept website.

## Stack
- Static HTML
- Tailwind CSS via CDN (Stitch export)
- Custom responsive/foldable hardening
- Local optimized WebP assets

## Deploy
The project is static and can be deployed directly to Vercel, Netlify, Cloudflare Pages, or GitHub Pages.

For Vercel, import the repository and deploy with no build command. The project root is the publish root.

## Notes
The reservation experience is a front-end demo and does not persist bookings to a backend.
